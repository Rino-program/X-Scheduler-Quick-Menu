# Privacy Policy

This extension stores schedule presets locally in `chrome.storage.local`.

## Data collected

- No personal data is intentionally collected by the extension.
- Schedule presets entered by the user are stored locally on the device.

## Data usage

- Stored presets are used only to populate the extension menu.
- No data is transmitted to external servers.

## Third-party services

- The extension interacts with `x.com` and `twitter.com` only through the browser page the user is already viewing.
